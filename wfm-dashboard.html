Cómo leer esta pestaña. Cada tarjeta de "caída" o "subida" fuerte Jul→Ago trae un diagnóstico automático que cruza el cambio de volumen con el cambio de tasa de contacto — así se puede distinguir un problema de dotación/prioridad (bajó el volumen, el contacto se sostuvo) de un problema de calidad/guion (el volumen se sostuvo pero bajó el contacto). Usa el filtro de operación de arriba para ver esto por operación.
